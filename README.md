# Diamond Coach

Baseball lineup and stats tracker for Guelph Royals.

## Setup

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository
2. Go to vercel.com, sign in with GitHub
3. Click "Add New Project" → select the repository
4. Click Deploy — done

## Tech Stack

- React 18 + Vite
- Recharts for charts
- localStorage for data persistence
